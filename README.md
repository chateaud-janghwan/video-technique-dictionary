# 영상 기법 도감

카메라 무빙, 피사체 중심 무빙, 다이나믹 편집, 샷 크기·앵글·구도, 장면 전환, 속도, 모션 그래픽까지 96가지 촬영·편집 기법과 추천 조합 12가지를 움직이는 카드로 보여주는 한 페이지짜리 사전입니다.

- 카드마다 실시간 3D 미리보기(three.js)가 재생됩니다. 화면에 보이는 카드만 렌더링해서 가볍게 돌아갑니다.
- 카드를 누르면 큰 화면, 편집 타임라인, 피사체 기준 카메라 도식이 열립니다.
- 기법마다 AI 영상 도구나 편집 요청에 바로 쓸 수 있는 프롬프트(한국어/영어)를 복사할 수 있습니다.

빌드 과정 없이 `index.html` 하나로 동작합니다.
